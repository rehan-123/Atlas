# Microsoft 365 admin center

> [!abstract] In plain words
> The main admin website for Microsoft 365: users, licenses, groups, billing, service health and message center.
>
> **What kind of tool is this?** The services inside Microsoft 365 (mail, files, Teams) and the API used to manage them.

**Made by:** [[Microsoft]] · **Category:** [[Cloud & SaaS]] › [[Microsoft 365 workloads]]

> [!info]+ Words on this page
> **API**: A way for programs and scripts to talk to a service directly, without the web page.
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> *More in the [[Glossary]].*

## In more detail

Central admin portal (admin.microsoft.com) for users, licences, groups, domains, service health and message center, linking out to Exchange, Teams, SharePoint, Entra and Intune admin centers.

## When it breaks: what to check first

| Problem | Check this first |
|---|---|
| A service looks broken for many users | Check Health > Service health first: it may be a Microsoft incident |
| License won't assign | Check usage location is set and there are free licences in the subscription |
