# Microsoft 365 Copilot

> [!abstract] In plain words
> Microsoft's AI assistant inside Word, Excel, Outlook, Teams and other apps. It can only see what the user already has access to.
>
> **What kind of tool is this?** AI assistants answer questions, write drafts and summarize information from your work data. Admins control what data they can see.

**Made by:** [[Microsoft]] · **Category:** [[Cloud & SaaS]] › [[AI assistants]]

> [!info]+ Words on this page
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **DLP**: Data loss prevention: rules that detect and stop sensitive data leaving.
> *More in the [[Glossary]].*

## In more detail

AI assistant grounded in Microsoft Graph data (mail, files, chats, meetings) respecting existing permissions; licensed per user; admin controls in the Microsoft 365 admin center.

## Good to know

- Before rolling it out, fix overshared SharePoint sites and Teams: Copilot will happily surface any file a user can technically open.
- Sensitivity labels and DLP in Purview also apply to what Copilot can use.
