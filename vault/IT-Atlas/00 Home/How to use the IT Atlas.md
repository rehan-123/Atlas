# How to use the IT Atlas

The IT Atlas has five kinds of page. Each one starts with a plain-English box, so you can read the top and stop if that's all you need.

| Page type | Where | Use it to |
|---|---|---|
| **Help desk guides** | [[Help Desk]] | fix an everyday problem: steps anyone can try, then what the tech checks |
| **Tools** | the numbered category folders, such as [[RMM]] or [[Backup & DR]] | look up a product: what it is, what breaks, where its logs are |
| **Concepts** | [[Concepts]] | understand the ideas behind the tools, with analogies and self-check questions |
| **Playbooks** | [[Playbooks]] | handle an alert step by step, and write the ticket |
| **Reference** | [[Reference]] | look up ports, event IDs, commands and the [[Glossary]] |

## Levels

Every note has a `level` property so each reader can find their depth:

| Level | Who it's for |
|---|---|
| **Junior** | L1 help desk and NOC technicians, and anyone new to IT |
| **Mid** | L2 systems administrators who own servers, identity, backups and the cloud tenant |
| **Senior** | L3 senior engineers and architects: design, deep troubleshooting, governance |
| **All** | Navigation and reference pages useful to everyone |

See [[Notes by level]] and the [[Career tracks]].

## Finding things

- **Ctrl+O** opens any note by name; aliases work too, so typing *LabTech* finds ConnectWise Automate.
- **Ctrl+Shift+F** searches inside every note.
- The **graph view** shows how everything connects; each category has its own colour.
- [[Tool database]] lists every tool in one table.

## What the boxes mean

- **In plain words** / **What this alert means**: the short version.
- **Think of it like**: an everyday comparison.
- **Words on this page**: meanings of the jargon used on that page.
- **Check yourself**: click a question to reveal the answer.
