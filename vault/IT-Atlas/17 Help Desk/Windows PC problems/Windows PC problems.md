# Windows PC problems

> [!abstract] In plain words
> Slow, frozen, crashing or broken Windows computers, screens, sound and keyboards.

Part of [[Help Desk]].

| Problem | What's going on |
|---|---|
| [[PC is slow]] | The computer takes ages to open things, or everything lags. |
| [[PC won't turn on]] | Pressing the power button does nothing, or lights come on but the screen stays black. |
| [[Computer won't start Windows]] | The PC turns on but gets stuck on the logo, keeps restarting, or shows a repair screen. |
| [[Blue screen (BSOD)]] | Windows crashed and showed a blue (or black) screen with a sad face and a stop code, then restarted. |
| [[Frozen app or Not Responding]] | One program stops reacting and its title bar says 'Not Responding'. |
| [[Windows updates stuck]] | Updates fail, keep retrying, or the PC sits on 'Working on updates' for a long time. |
| [[No sound or microphone]] | You can't hear anything, or others can't hear you on calls. |
| [[Screen or second monitor not working]] | A monitor shows 'No signal', flickers, or Windows doesn't see the second screen. |
| [[Keyboard or mouse not working]] | Keys or the mouse pointer don't respond, or respond strangely. |
| [[Disk full on a PC]] | The C: drive is red in File Explorer, and apps or updates fail because there's no space. |
| [[Laptop battery drains fast]] | The battery runs out much faster than it used to. |
| [[Laptop overheating or loud fan]] | The laptop is hot, the fan runs loudly all the time, or it slows down when warm. |
| [[Bluetooth device won't pair]] | A Bluetooth headset, mouse or keyboard won't connect. |
| [[Webcam not detected]] | The camera shows nothing, or apps say no camera was found. |
| [[Docking station not working]] | Monitors, keyboard or network through the dock stop working. |
| [[Time or date is wrong]] | The PC's clock is wrong, which can break sign-ins and secure websites. |
| [[Windows not activated]] | Windows shows 'Activate Windows' or a licensing warning. |
