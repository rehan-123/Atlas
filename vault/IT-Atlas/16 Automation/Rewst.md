# Rewst

> [!abstract] In plain words
> An automation platform for MSPs: it connects the PSA, RMM and Microsoft 365 to automate things like onboarding a new user.
>
> **What kind of tool is this?** Scripting and automation tools let you do a task once in code and then repeat it on hundreds of machines.

**Made by:** [[Rewst]] · **Runs:** SaaS · **Category:** [[Automation & Scripting]]

> [!info]+ Words on this page
> **MSP**: Managed service provider: a company that runs IT for other companies.
> **PSA**: Professional services automation: the MSP's ticketing, time and billing system.
> **RMM**: Remote monitoring and management: the MSP's main tool for watching and fixing client machines.
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **onboarding**: Setting up a new starter's accounts, access and devices.
> **offboarding**: Removing a leaver's access while keeping their data for the business.
> *More in the [[Glossary]].*

## In more detail

Automation platform built for MSPs, with integrations across PSAs, RMMs, Microsoft 365 and documentation tools (onboarding, offboarding, ticket triage).
