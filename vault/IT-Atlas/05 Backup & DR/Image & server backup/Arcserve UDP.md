# Arcserve UDP

> [!abstract] In plain words
> Arcserve's backup software for servers and VMs.
>
> **What kind of tool is this?** Image backup copies a whole machine (operating system, apps and data) so it can be rebuilt exactly as it was.

**Made by:** [[Arcserve]] · **Runs:** On-prem with optional cloud · **Category:** [[Backup & DR]] › [[Image & server backup]]

> [!info]+ Words on this page
> **UDP**: A fast network protocol that doesn't confirm delivery.
> **VM**: Virtual machine: a computer that runs as software on a physical server.
> **DR**: Disaster recovery: getting systems back after a major failure.
> **agent**: A small program installed on a computer that reports to, and takes orders from, a central console.
> **deduplication**: Storing identical chunks of data only once to save space.
> *More in the [[Glossary]].*

## In more detail

Arcserve Unified Data Protection: agent and agentless backup with global deduplication and recovery point servers.
