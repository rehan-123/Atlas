# Uptime Kuma

> [!abstract] In plain words
> A free, self-hosted tool that checks websites and services are up and shows a status page.
>
> **What kind of tool is this?** Uptime monitors check from the outside, like a customer would, that a website or service still answers.

**Runs:** Self-hosted (open source) · **Category:** [[Monitoring & Observability]] › [[Uptime monitoring]]

> [!info]+ Words on this page
> **HTTP**: The protocol web pages use (port 80, unencrypted).
> **TCP**: A connection-based network protocol that confirms delivery.
> **DNS**: The service that turns names (like server01.contoso.local) into IP addresses.
> **ping**: A quick test that sends a small message to a device and waits for a reply.
> **port**: A numbered door on a device that a specific service listens on, for example 443 for HTTPS or 3389 for RDP.
> *More in the [[Glossary]].*

## In more detail

Self-hosted uptime monitor for HTTP, TCP, ping, DNS and more, with status pages and many notification channels.

## Network ports it uses

Firewalls between the parts of this tool must allow these:

- 3001/TCP web UI
