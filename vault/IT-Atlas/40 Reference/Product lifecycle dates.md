# Product lifecycle dates

End-of-support dates that drive upgrade work. Verify against the vendor's lifecycle site before quoting to a client.

| Product | End of support |
|---|---|
| Windows 10 | 14 October 2025 (ESU available) |
| Windows Server 2012 / 2012 R2 | 10 October 2023 (ESU available) |
| Windows Server 2016 | 12 January 2027 |
| Windows Server 2019 | 9 January 2029 |
| Windows Server 2022 | 14 October 2031 |
| Exchange Server 2016 / 2019 | 14 October 2025 |
| Office 2016 / 2019 | 14 October 2025 |
| SQL Server 2014 | 9 July 2024 |
| SQL Server 2016 | 14 July 2026 |
| SQL Server 2017 | 12 October 2027 |
| VMware vSphere 7 | 2 October 2025 (general support) |

Track unsupported systems as risks on each client's documentation.
