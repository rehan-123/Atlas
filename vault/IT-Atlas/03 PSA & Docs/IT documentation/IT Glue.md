# IT Glue

> [!abstract] In plain words
> Where many MSPs keep client documentation: devices, passwords, network details and how-to guides.
>
> **What kind of tool is this?** Documentation tools hold everything you need to know about each client: devices, passwords, network details and how-to guides.

**Made by:** [[Kaseya]] · **Runs:** SaaS · **Category:** [[PSA & Documentation]] › [[IT documentation]]

> [!info]+ Words on this page
> **MSP**: Managed service provider: a company that runs IT for other companies.
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **PSA**: Professional services automation: the MSP's ticketing, time and billing system.
> **RMM**: Remote monitoring and management: the MSP's main tool for watching and fixing client machines.
> *More in the [[Glossary]].*

## In more detail

Structured documentation for MSPs: organizations, configurations, flexible assets, passwords and SOPs, synced from RMM and PSA.

## Main parts

- Organizations and configurations
- Flexible assets
- Passwords (with access control)
- Documents and SOPs
- Integrations with PSA, RMM and Microsoft 365
