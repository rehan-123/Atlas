# WhatsUp Gold

> [!abstract] In plain words
> A network monitoring tool from Progress that draws maps of your devices.
>
> **What kind of tool is this?** Network monitoring tools keep checking routers, switches, firewalls and servers over the network and alert you when something stops answering or gets overloaded.

**Made by:** [[Progress]] · **Runs:** On-prem · **Category:** [[Monitoring & Observability]] › [[Network monitoring]]

Progress' network monitoring tool (originally Ipswitch) with discovery, layer 2 maps, flow and alerting.
