# Help desk skills

How to troubleshoot, ask good questions, talk to users and write tickets.

Part of [[Concepts]].

- [[Troubleshooting method]]: Six steps that work for any IT problem: understand, reproduce, isolate, fix, verify, record.
- [[Asking good questions]]: The right questions find the problem faster than any tool.
- [[Writing a good ticket]]: A ticket someone else can pick up without calling the user again.
- [[Talking to users]]: Calm, clear and kind: people remember how you made them feel.
- [[Remote support etiquette]]: How to behave when you're on someone else's screen.
