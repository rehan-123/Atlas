# Duo Security

> [!abstract] In plain words
> Adds a phone approval (MFA) step to VPN, RDP and Windows logins.
>
> **What kind of tool is this?** Identity tools hold user accounts and decide who can sign in to what. When identity breaks, nobody can work.

**Made by:** [[Cisco]] · **Runs:** Cloud · **Category:** [[Identity & Access]]

> [!info]+ Words on this page
> **MFA**: Multi-factor authentication: password plus a second proof, such as a phone prompt.
> **VPN**: An encrypted tunnel over the internet to a private network.
> **RDP**: Remote Desktop Protocol: Windows' built-in remote desktop, on port 3389.
> **SSO**: Single sign-on: one login for many apps.
> **LDAP**: The protocol apps use to look up users and groups in a directory.
> **proxy**: A middleman server that passes traffic on, for web filtering or to do work for a central server.
> *More in the [[Glossary]].*

## In more detail

MFA and device trust: push and passcode MFA for VPN, RDP and Windows logon, SSO, and the Duo Authentication Proxy for RADIUS and LDAP integrations.

## Main parts

- Duo Authentication Proxy (RADIUS and LDAP)
- Duo for Windows Logon and RDP
- Duo Universal Prompt for SSO
