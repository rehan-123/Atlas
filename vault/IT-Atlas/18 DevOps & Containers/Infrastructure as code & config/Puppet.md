# Puppet

> [!abstract] In plain words
> A configuration management tool that keeps many servers in a defined state.
>
> **What kind of tool is this?** Infrastructure as code means writing servers, networks and settings down in files, so building them is a repeatable command instead of a checklist.

**Made by:** [[Perforce]] · **Category:** [[DevOps & Containers]] › [[Infrastructure as code & config]]

> [!info]+ Words on this page
> **container**: A packaged app with everything it needs to run, sharing the host's operating system kernel.
> **agent**: A small program installed on a computer that reports to, and takes orders from, a central console.
> *More in the [[Glossary]].*

## In more detail

Agent-based configuration management: manifests describe desired state, agents check in and enforce it.
