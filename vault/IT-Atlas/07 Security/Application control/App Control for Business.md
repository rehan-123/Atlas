# App Control for Business

> [!abstract] In plain words
> Windows' built-in way to allow only approved apps (formerly WDAC; AppLocker is the older version).
>
> **What kind of tool is this?** Application control only lets approved programs run, so unknown or malicious software is blocked by default.

**Made by:** [[Microsoft]] · **Runs:** Built into Windows · **Category:** [[Security]] › [[Application control]]

## In more detail

Windows' built-in application control (formerly WDAC), with AppLocker as the older, simpler option. Deployable through Intune or Group Policy.
