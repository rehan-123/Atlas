# Amazon Web Services

> [!abstract] In plain words
> Amazon's public cloud, the largest one.
>
> **What kind of tool is this?** Public clouds rent out servers, storage and networking by the hour from huge data centers.

**Made by:** [[Amazon Web Services]] · **Runs:** Cloud · **Category:** [[Cloud & SaaS]] › [[Public cloud]]

> [!info]+ Words on this page
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **RDS**: Remote Desktop Services: many users working on one shared Windows server.
> *More in the [[Glossary]].*

## In more detail

The largest public cloud: EC2, VPC, IAM, S3, RDS and Systems Manager, monitored with CloudWatch.

## Handy commands

Words in CAPITALS are placeholders: replace them with your own values before running.

```
aws sts get-caller-identity
aws ec2 describe-instances --output table
```
