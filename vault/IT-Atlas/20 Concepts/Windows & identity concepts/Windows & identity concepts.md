# Windows & identity concepts

Authentication, directory and Windows internals.

Part of [[Concepts]].

- [[Kerberos]]: Active Directory's default authentication protocol, using tickets from the KDC on domain controllers.
- [[NTLM]]: Legacy challenge-response authentication, used when Kerberos cannot be (IP addresses, workgroups, some old apps).
- [[LDAP]]: Lightweight Directory Access Protocol: how apps query and bind to Active Directory.
- [[FSMO roles]]: Five single-master roles in Active Directory.
- [[Certificates & PKI]]: Public key infrastructure: certificate authorities issue certificates that prove identity and enable encryption.
- [[RAID levels]]: How disks are combined for redundancy and performance.
- [[SMART]]: Self-Monitoring, Analysis and Reporting Technology: drive health data that predicts failure.
- [[Windows Event Log]]: Where Windows records what happened: System, Application, Security and many Applications and Services logs.
