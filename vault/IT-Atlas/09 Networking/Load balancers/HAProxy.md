# HAProxy

> [!abstract] In plain words
> A free, fast load balancer.
>
> **What kind of tool is this?** A load balancer spreads incoming traffic across several servers, so one busy or failed server doesn't take a service down.

**Made by:** [[HAProxy Technologies]] · **Runs:** Open source or enterprise · **Category:** [[Networking]] › [[Load balancers]]

> [!info]+ Words on this page
> **TCP**: A connection-based network protocol that confirms delivery.
> **HTTP**: The protocol web pages use (port 80, unencrypted).
> **proxy**: A middleman server that passes traffic on, for web filtering or to do work for a central server.

High-performance open-source TCP and HTTP load balancer and reverse proxy.
