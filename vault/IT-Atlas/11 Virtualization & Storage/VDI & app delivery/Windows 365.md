# Windows 365

> [!abstract] In plain words
> A personal Windows PC in the cloud for each user, for a monthly fee.
>
> **What kind of tool is this?** VDI gives users a desktop that actually runs in the data center or cloud, which they reach over the network.

**Made by:** [[Microsoft]] · **Runs:** SaaS · **Category:** [[Virtualization & Storage]] › [[VDI & app delivery]]

> [!info]+ Words on this page
> **VDI**: Virtual desktop infrastructure: desktops that run on servers and are used remotely.
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> *More in the [[Glossary]].*

## In more detail

Per-user Cloud PCs from Microsoft at a fixed monthly price, managed in Intune.
