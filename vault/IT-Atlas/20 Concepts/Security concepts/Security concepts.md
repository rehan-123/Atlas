# Security concepts

The security ideas a NOC engineer needs daily.

Part of [[Concepts]].

- [[Zero Trust]]: Never trust by network location; verify identity, device and context for every access.
- [[Multi-factor authentication]]: Requiring two or more factors to sign in.
- [[Least privilege]]: Give accounts and apps only the access they need, only when they need it.
- [[EDR vs MDR vs XDR]]: Terms you will see on every security product.
- [[CVE & CVSS]]: CVE IDs name vulnerabilities; CVSS scores their severity from 0 to 10.
- [[Patch Tuesday]]: Microsoft releases security updates on the second Tuesday of each month.
- [[SPF, DKIM & DMARC]]: Email authentication records that stop spoofing and improve delivery.
