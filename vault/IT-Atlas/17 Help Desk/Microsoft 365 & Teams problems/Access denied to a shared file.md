# Access denied to a shared file

> [!abstract] What's going on
> 'You need permission to access this item' when opening a shared link.

> [!tip] Think of it like
> A party invitation addressed to someone else: the door won't open even though you have the address.

**Who can fix it:** Anyone can do the first steps; a tech does the rest. · **Area:** [[Microsoft 365 & Teams problems]]

> [!info]+ Words on this page
> **escalate**: Hand a problem to a more senior person or team, with your notes.
> *More in the [[Glossary]].*

## Try this first

Anyone can do these, and they fix most cases.

1. Make sure you're signed in with your work account, not a personal one.
2. Click 'Request access' so the owner gets a request.
3. Ask the sender to share it with your exact email address.

## If you're the tech

Words in CAPITALS are placeholders: replace them with your own values.

- Check the site or folder permissions and the link type (specific people, organization, anyone).
- Check external sharing settings if the user is a guest.
- Check whether the file sits in a library with unique (broken) permissions.

## Common causes and fixes

| Cause | Fix |
|---|---|
| Signed in with the wrong account | Switch accounts. |
| Link for specific people only | Owner shares with the right address. |
| External sharing blocked | Admin reviews sharing policy. |

## Escalate when

- Request is for confidential data: the owner must approve
