# Jenkins

> [!abstract] In plain words
> An older, very flexible open-source automation server for building and deploying software.
>
> **What kind of tool is this?** Source control keeps every version of code and scripts. CI/CD pipelines test and deploy changes automatically when someone pushes.

**Made by:** [[Jenkins project]] · **Runs:** Self-hosted (Java) · **Category:** [[DevOps & Containers]] › [[Source control & pipelines]]

> [!info]+ Words on this page
> **CI/CD**: Continuous integration and delivery: automatic testing and deployment of every change.
> **pipeline**: A series of automated steps (test, build, deploy) that run on every change.
> **container**: A packaged app with everything it needs to run, sharing the host's operating system kernel.
> **agent**: A small program installed on a computer that reports to, and takes orders from, a central console.
> *More in the [[Glossary]].*

## In more detail

Self-hosted CI/CD server with a large plugin ecosystem; pipelines defined in a Jenkinsfile; agents run the jobs.

## Good to know

- Plugins need regular updates; outdated Jenkins servers are a common attack target.
