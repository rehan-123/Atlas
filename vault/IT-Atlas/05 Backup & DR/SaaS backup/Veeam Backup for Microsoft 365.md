# Veeam Backup for Microsoft 365

> [!abstract] In plain words
> Veeam's Microsoft 365 backup, which you run yourself or buy through a provider.
>
> **What kind of tool is this?** SaaS backup keeps your own copy of Microsoft 365 or Google data (mail, OneDrive, SharePoint, Teams). Microsoft and Google keep the service running, but restoring deleted or encrypted data is your job.

**Made by:** [[Veeam]] · **Runs:** Self-hosted or via a service provider · **Category:** [[Backup & DR]] › [[SaaS backup]]

> [!info]+ Words on this page
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **DR**: Disaster recovery: getting systems back after a major failure.
> *More in the [[Glossary]].*

## In more detail

Veeam's Microsoft 365 backup: you run the backup server, proxies and repositories (often object storage), or buy it from a service provider.

## Main parts

- Backup server and proxies
- Repositories (local or object storage)
- Organization added through an Entra ID app registration
- Restore Portal and Explorers
