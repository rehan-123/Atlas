# Veeam Agent for Microsoft Windows

> [!abstract] In plain words
> Veeam's backup agent for physical Windows machines.
>
> **What kind of tool is this?** Endpoint backup protects laptops and desktops, usually by sending copies straight to the cloud.

**Made by:** [[Veeam]] · **Runs:** Standalone or managed by VBR · **Category:** [[Backup & DR]] › [[Endpoint backup]]

> [!info]+ Words on this page
> **DR**: Disaster recovery: getting systems back after a major failure.
> **VM**: Virtual machine: a computer that runs as software on a physical server.
> **agent**: A small program installed on a computer that reports to, and takes orders from, a central console.
> **endpoint**: Any device a user works on: laptop, desktop, phone or server.
> **replication**: Copying data or changes to another place, continuously or on a schedule.
> *More in the [[Glossary]].*

## In more detail

Veeam's agent for physical Windows machines and cloud VMs. Free edition standalone; licensed when managed from Veeam Backup & Replication.
