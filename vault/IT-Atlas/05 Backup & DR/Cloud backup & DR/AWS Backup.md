# AWS Backup

> [!abstract] In plain words
> AWS's built-in backup service for AWS resources.
>
> **What kind of tool is this?** These are the backup and disaster-recovery services built into Azure and AWS, plus tools that keep a live copy of servers in another location.

**Made by:** [[Amazon Web Services]] · **Runs:** AWS · **Category:** [[Backup & DR]] › [[Cloud backup & DR]]

> [!info]+ Words on this page
> **DR**: Disaster recovery: getting systems back after a major failure.
> **RDS**: Remote Desktop Services: many users working on one shared Windows server.
> *More in the [[Glossary]].*

## In more detail

Policy-based backup for AWS services (EC2, EBS, RDS, EFS, S3 and more) with backup plans, vaults and Vault Lock for immutability.
