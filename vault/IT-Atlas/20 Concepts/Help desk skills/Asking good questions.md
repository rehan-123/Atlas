# Asking good questions

> [!abstract] In one line
> The right questions find the problem faster than any tool.

> [!tip] Think of it like
> A good mechanic asks 'when does the noise happen?' before opening the bonnet.

## How it works

- What exactly do you see? (Ask for the error message or a screenshot.)
- When did it start? Did it ever work?
- Does it happen every time, or sometimes?
- Is anyone else affected?
- What changed: new password, new device, update, moved desk, working from home?
- How urgent is it: can you work at all?

## Check yourself

Answer in your head first, then click to reveal.

> [!question]- Which question tells you whether it's one user's problem or a bigger outage?
> 'Is anyone else affected?'
