# Zscaler

> [!abstract] In plain words
> Cloud security that filters internet traffic and gives secure access to company apps without a traditional VPN.
>
> **What kind of tool is this?** These cloud services replace the old office VPN: users get to the apps they're allowed to use, from anywhere, with security checks on every connection.

**Made by:** [[Zscaler]] · **Runs:** Cloud · **Category:** [[Security]] › [[SASE & ZTNA]]

> [!info]+ Words on this page
> **VPN**: An encrypted tunnel over the internet to a private network.
> **SASE**: Cloud-delivered network security that protects users wherever they are.
> **ZTNA**: Zero-trust network access: app-by-app access with checks on every connection, replacing a broad VPN.
> *More in the [[Glossary]].*

## In more detail

Cloud security platform: Zscaler Internet Access (secure web gateway) and Zscaler Private Access (ZTNA to internal apps) through the Client Connector.
