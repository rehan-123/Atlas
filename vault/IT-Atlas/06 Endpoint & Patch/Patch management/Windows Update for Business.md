# Windows Update for Business

> [!abstract] In plain words
> Controls Windows updates from the cloud: which devices update first and how long others wait.
>
> **What kind of tool is this?** Patching means installing updates, mostly security fixes. These tools decide what gets installed, when, and report what's missing.

**Made by:** [[Microsoft]] · **Runs:** Cloud policy · **Category:** [[Endpoint & Patch Management]] › [[Patch management]]

> [!info]+ Words on this page
> **endpoint**: Any device a user works on: laptop, desktop, phone or server.
> *More in the [[Glossary]].*

## In more detail

Policy-based control of Windows Update from the cloud: rings, deferrals and deadlines via Intune or Group Policy. Windows Autopatch automates ring management on top.
