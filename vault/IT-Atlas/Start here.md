# Start here

Welcome to the IT Atlas: everything IT, from everyday fixes to running a NOC, explained in plain English.

1. **New to IT?** Open [[Learning path]] and start with Week 1.
1. **Someone has a computer problem?** Open [[Help Desk]] and pick the problem.
2. **Handling an alert right now?** Open [[Playbooks]] and pick the alert.
3. **Looking up a product?** Press Ctrl+O and type its name.
4. **Don't know a word?** Every page explains its own terms, and the [[Glossary]] has the rest.

More on finding your way around: [[How to use the IT Atlas]]. The main menu is [[Home]].

## One-time setup
- Turn on the **Dataview** plugin if the installer didn't (Settings > Community plugins). It powers the tables on [[Home]] and the category pages.
- To have Claude add and update notes, open a terminal in this folder and run `claude`. Try `/add-tool`, `/add-playbook`, `/verify`, `/gaps` or `/lint`.

## About accuracy
The content reflects general knowledge as of 2026-06. Product names, owners, ports and paths change, and anything marked "(verify)" is known to be uncertain. Each tool has a `verified` field; running `/verify` checks a note against the vendor's documentation and records the date and source.
