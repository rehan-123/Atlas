# Azure Blob Storage

> [!abstract] In plain words
> Azure's storage service for files, also used as a backup target.
>
> **What kind of tool is this?** These are the places backups get stored in the cloud. Many can lock a backup so nobody, not even an attacker with admin rights, can delete it early.

**Made by:** [[Microsoft]] · **Runs:** Cloud object storage · **Category:** [[Backup & DR]] › [[Backup storage targets]]

> [!info]+ Words on this page
> **DR**: Disaster recovery: getting systems back after a major failure.
> *More in the [[Glossary]].*

## In more detail

Azure object storage with hot, cool, cold and archive tiers and immutability policies. Used as a backup target and for archive tiers.
