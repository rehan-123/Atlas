# Chocolatey

> [!abstract] In plain words
> A command-line app installer for Windows with a big library of apps.
>
> **What kind of tool is this?** Software deployment tools install or update apps on many computers at once, without clicking through installers.

**Made by:** [[Chocolatey Software]] · **Runs:** Open source with commercial editions · **Category:** [[Endpoint & Patch Management]] › [[Software deployment]]

> [!info]+ Words on this page
> **endpoint**: Any device a user works on: laptop, desktop, phone or server.
> **repository**: Where backups are stored.
> *More in the [[Glossary]].*

## In more detail

Package manager for Windows with a large community repository; business editions add internal repositories and self-service.

## Handy commands

Words in CAPITALS are placeholders: replace them with your own values before running.

```
choco install PACKAGE -y
choco upgrade all -y
choco list
```
