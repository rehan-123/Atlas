# Security policy

Atlas is a community knowledge base, not a supported security product. Treat commands and procedures as examples: verify them against current vendor documentation and your organization's controls before use.

## Reporting a concern

Do not publish credentials, customer information, private infrastructure details, or a live exploit in an issue. For a sensitive report, contact the repository owner privately through GitHub. Include the affected file or feature, impact, and safe reproduction details. Avoid attaching real logs or customer data.

## Using the vault safely

- Review community plugins before enabling them. The vault includes third-party plugin code; see each plugin's notices.
- The Gesture Graph hand-control feature uses the camera only after it is enabled and processes frames on-device, according to its included documentation.
- Confirm a command's scope and impact before running it, especially in production.
- Never put credentials or private organization data into notes, examples, issues, or pull requests.
