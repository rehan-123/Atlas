# F5 BIG-IP

> [!abstract] In plain words
> A high-end load balancer for big web applications.
>
> **What kind of tool is this?** A load balancer spreads incoming traffic across several servers, so one busy or failed server doesn't take a service down.

**Made by:** [[F5]] · **Runs:** Appliance or VM · **Category:** [[Networking]] › [[Load balancers]]

> [!info]+ Words on this page
> **VM**: Virtual machine: a computer that runs as software on a physical server.
> **SSL**: The old name for TLS encryption.
> **CVE**: A public ID number for a specific security vulnerability.
> **appliance**: A dedicated box (or virtual machine) built to do one job, such as backup or firewall.

## In more detail

Enterprise application delivery controller: local traffic management, SSL offload, WAF and access policy.

## Good to know

- The management interface (TMUI) has had critical exploited CVEs; keep it off the internet.
