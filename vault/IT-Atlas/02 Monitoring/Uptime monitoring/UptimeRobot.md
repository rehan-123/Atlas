# UptimeRobot

> [!abstract] In plain words
> A cloud service that checks your websites every few minutes and alerts you when they're down.
>
> **What kind of tool is this?** Uptime monitors check from the outside, like a customer would, that a website or service still answers.

**Made by:** [[UptimeRobot]] · **Runs:** SaaS · **Category:** [[Monitoring & Observability]] › [[Uptime monitoring]]

> [!info]+ Words on this page
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **HTTP**: The protocol web pages use (port 80, unencrypted).
> **SSL**: The old name for TLS encryption.
> **ping**: A quick test that sends a small message to a device and waits for a reply.
> **port**: A numbered door on a device that a specific service listens on, for example 443 for HTTPS or 3389 for RDP.
> *More in the [[Glossary]].*

## In more detail

SaaS uptime monitoring from multiple locations: HTTP(S), keyword, ping, port and SSL expiry checks, with status pages.
