# Prints look wrong

> [!abstract] What's going on
> Pages come out with strange symbols, faded, streaky or in the wrong size.

> [!tip] Think of it like
> Two people speaking different languages: the PC (driver) must speak the printer's language.

**Who can fix it:** Anyone can do the first steps; a tech does the rest. · **Area:** [[Printer & scanner problems]]

> [!info]+ Words on this page
> **driver**: Small program that lets the operating system talk to a piece of hardware, like a printer or graphics card.
> **escalate**: Hand a problem to a more senior person or team, with your notes.
> *More in the [[Glossary]].*

## Try this first

Anyone can do these, and they fix most cases.

1. Print a test page from the printer's own menu: if that's bad too, it's the printer (toner, drum).
2. Check the paper size (A4 vs Letter) in the print dialog.
3. Replace low toner.

## If you're the tech

Words in CAPITALS are placeholders: replace them with your own values.

- Install the correct, current driver for the exact model (avoid generic drivers for complex printers).
- Try the PCL vs PostScript driver if pages print garbage symbols.
- Check the document settings: scale, paper size, tray.

## Common causes and fixes

| Cause | Fix |
|---|---|
| Wrong or generic driver | Install the model's own driver. |
| Toner or drum worn | Replace consumables. |
| Paper size mismatch | Set the right size. |

## Escalate when

- The printer's own test page is bad (hardware service needed)
