# Essential Eight

> [!abstract] In one line
> Australia's eight priority mitigation strategies against cyber attacks, measured at maturity levels.

> [!tip] Think of it like
> Eight locks that stop most burglars, each fitted to a stronger standard as you mature.

> [!info]+ Words on this page
> **MFA**: Multi-factor authentication: password plus a second proof, such as a phone prompt.
> **hardening**: Changing default settings to remove unnecessary features and close security gaps.
> *More in the [[Glossary]].*

## How it works

- Application control, patching applications, configuring Microsoft Office macros, user application hardening, restricting admin privileges, patching operating systems, MFA, and regular backups.
- Maturity levels one to three describe how thoroughly each is implemented.
