# Root cause analysis

> [!abstract] In one line
> Finding why an incident happened so it does not repeat.

> [!tip] Think of it like
> Asking 'why?' until you reach something you can fix so it never happens again.

> [!info]+ Words on this page
> **NOC**: Network operations center: the team that monitors and fixes infrastructure.
> *More in the [[Glossary]].*

## How it works

- Separate trigger, root cause and contributing factors. "Human error" is never a root cause.
- An 8-point NOC format: summary, impact, timeline, detection, investigation, root cause, resolution, prevention.
- If the root cause is not confirmed, say so and list what evidence would confirm it.

## Check yourself

Answer in your head first, then click to reveal.

> [!question]- Is 'human error' a root cause?
> No. Ask what allowed the error to happen and fix that.
