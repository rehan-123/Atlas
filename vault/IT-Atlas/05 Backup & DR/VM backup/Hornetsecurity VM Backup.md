# Hornetsecurity VM Backup

> [!abstract] In plain words
> Simple VM backup for Hyper-V and VMware, formerly called Altaro.
>
> **What kind of tool is this?** VM backup protects virtual machines from the host level, without installing software inside each one.

**Made by:** [[Hornetsecurity]] · **Runs:** On-prem · **Category:** [[Backup & DR]] › [[VM backup]]

> **SMB**: The Windows file-sharing protocol (port 445).
