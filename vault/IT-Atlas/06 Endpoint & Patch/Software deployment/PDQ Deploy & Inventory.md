# PDQ Deploy & Inventory

> [!abstract] In plain words
> Pushes software and scripts to many Windows PCs at once, and lists what's installed on each.
>
> **What kind of tool is this?** Software deployment tools install or update apps on many computers at once, without clicking through installers.

**Made by:** [[PDQ]] · **Runs:** On-prem or PDQ Connect (cloud) · **Category:** [[Endpoint & Patch Management]] › [[Software deployment]]

> [!info]+ Words on this page
> **endpoint**: Any device a user works on: laptop, desktop, phone or server.
> *More in the [[Glossary]].*

## In more detail

Push software and scripts to Windows machines and inventory them; PDQ Connect is the cloud agent-based version.
