# Domotz

> [!abstract] In plain words
> Cloud network monitoring for MSPs, using a small box or agent at each site.
>
> **What kind of tool is this?** Network monitoring tools keep checking routers, switches, firewalls and servers over the network and alert you when something stops answering or gets overloaded.

**Made by:** [[Domotz]] · **Runs:** SaaS with on-site collector · **Category:** [[Monitoring & Observability]] › [[Network monitoring]]

> [!info]+ Words on this page
> **MSP**: Managed service provider: a company that runs IT for other companies.
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **LAN**: Local area network: the network inside a building.
> **agent**: A small program installed on a computer that reports to, and takes orders from, a central console.
> **router**: Device that connects one network to another, such as the office to the internet.
> *More in the [[Glossary]].*

## In more detail

Cloud network monitoring and remote access for MSPs, using a small on-site collector to discover and monitor everything on the LAN.
