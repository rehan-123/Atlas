# Amazon S3

> [!abstract] In plain words
> AWS's storage service for files of any size, with options from fast to very cheap archive.
>
> **What kind of tool is this?** These are the places backups get stored in the cloud. Many can lock a backup so nobody, not even an attacker with admin rights, can delete it early.

**Made by:** [[Amazon Web Services]] · **Runs:** Cloud object storage · **Category:** [[Backup & DR]] › [[Backup storage targets]]

> **DR**: Disaster recovery: getting systems back after a major failure.

## In more detail

AWS object storage with storage classes from Standard to Glacier Deep Archive, Object Lock for immutability and lifecycle rules.
