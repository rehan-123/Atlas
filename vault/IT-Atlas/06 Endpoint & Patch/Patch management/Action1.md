# Action1

> [!abstract] In plain words
> Cloud patching and basic remote management.
>
> **What kind of tool is this?** Patching means installing updates, mostly security fixes. These tools decide what gets installed, when, and report what's missing.

**Made by:** [[Action1]] · **Runs:** SaaS · **Category:** [[Endpoint & Patch Management]] › [[Patch management]]

> **RMM**: Remote monitoring and management: the MSP's main tool for watching and fixing client machines.
> **endpoint**: Any device a user works on: laptop, desktop, phone or server.
