# Kemp LoadMaster

> [!abstract] In plain words
> A load balancer often used in front of Exchange and remote desktop servers.
>
> **What kind of tool is this?** A load balancer spreads incoming traffic across several servers, so one busy or failed server doesn't take a service down.

**Made by:** [[Progress]] · **Runs:** Appliance or VM · **Category:** [[Networking]] › [[Load balancers]]

> [!info]+ Words on this page
> **VM**: Virtual machine: a computer that runs as software on a physical server.
> **RDS**: Remote Desktop Services: many users working on one shared Windows server.
> **appliance**: A dedicated box (or virtual machine) built to do one job, such as backup or firewall.
> *More in the [[Glossary]].*

Load balancer popular for Exchange, RDS and IIS, now owned by Progress.
