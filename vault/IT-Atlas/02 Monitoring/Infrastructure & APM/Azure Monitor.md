# Azure Monitor

> [!abstract] In plain words
> Azure's built-in monitoring: graphs, logs and alerts for Azure resources and connected servers.
>
> **What kind of tool is this?** These tools collect numbers (CPU, memory, response times) from servers, apps and cloud services and draw them as graphs, so you can spot trouble before users notice.

**Made by:** [[Microsoft]] · **Runs:** Cloud · **Category:** [[Monitoring & Observability]] › [[Infrastructure & APM]]

> [!info]+ Words on this page
> **CPU**: The processor, the part of a computer that does the calculations.
> **KQL**: Kusto Query Language, used to search logs in Sentinel, Defender and Azure Monitor.
> **VM**: Virtual machine: a computer that runs as software on a physical server.
> **agent**: A small program installed on a computer that reports to, and takes orders from, a central console.

## In more detail

Azure's native monitoring: metrics, Log Analytics workspaces queried with KQL, alerts and action groups, and the Azure Monitor Agent for VMs and Arc servers.

## Main parts

- Metrics
- Log Analytics workspaces (KQL)
- Alert rules and action groups
- Azure Monitor Agent and data collection rules
