# Ansible

> [!abstract] In plain words
> Applies the same configuration to many servers at once from a simple text file.
>
> **What kind of tool is this?** Scripting and automation tools let you do a task once in code and then repeat it on hundreds of machines.

**Made by:** [[Red Hat]] · **Runs:** Control node with agentless SSH or WinRM · **Category:** [[Automation & Scripting]]

> [!info]+ Words on this page
> **SSH**: Secure Shell: encrypted command-line login, mostly for Linux and network devices (port 22).
> **YAML**: A plain-text format used for configuration files and pipeline definitions; indentation matters.
> *More in the [[Glossary]].*

## In more detail

Agentless configuration management: playbooks in YAML push configuration over SSH or WinRM.
