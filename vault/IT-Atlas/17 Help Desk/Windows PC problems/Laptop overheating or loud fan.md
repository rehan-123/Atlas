# Laptop overheating or loud fan

> [!abstract] What's going on
> The laptop is hot, the fan runs loudly all the time, or it slows down when warm.

> [!tip] Think of it like
> A runner in a winter coat: blocked vents and heavy work make it overheat.

**Who can fix it:** Anyone can do the first steps; a tech does the rest. · **Area:** [[Windows PC problems]]

> [!info]+ Words on this page
> **Task Manager**: Windows tool (Ctrl+Shift+Esc) that shows running apps and what's using CPU, memory and disk.
> **CPU**: The processor, the part of a computer that does the calculations.
> **BIOS**: The low-level setup program that starts a PC before Windows loads (UEFI on modern PCs).
> **browser**: The app you use to open websites: Edge, Chrome, Safari or Firefox.
> **driver**: Small program that lets the operating system talk to a piece of hardware, like a printer or graphics card.
> **firmware**: The software built into hardware such as firewalls, disks and servers.
> **escalate**: Hand a problem to a more senior person or team, with your notes.
> *More in the [[Glossary]].*

## Try this first

Anyone can do these, and they fix most cases.

1. Use it on a hard, flat surface, not a bed or lap.
2. Close heavy apps and browser tabs.
3. Restart it.

## If you're the tech

Words in CAPITALS are placeholders: replace them with your own values.

- Check Task Manager for processes using lots of CPU.
- Update BIOS and drivers; vendors often fix fan control.
- Clean vents (or send for service) if dust is visible.
- Check the power plan isn't stuck on maximum performance.

## Common causes and fixes

| Cause | Fix |
|---|---|
| Blocked vents | Hard surface, clean vents. |
| Heavy background process | Find and stop it. |
| Old firmware | Update BIOS. |

## Escalate when

- It shuts down from heat
- Fan makes grinding noises (hardware)

> [!question]- Why does a laptop slow down when it gets hot?
