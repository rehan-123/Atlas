# Azure Logic Apps

> [!abstract] In plain words
> Azure's drag-and-drop workflow service for automating tasks between apps, like Power Automate but for IT and developers.
>
> **What kind of tool is this?** Scripting and automation tools let you do a task once in code and then repeat it on hundreds of machines.
