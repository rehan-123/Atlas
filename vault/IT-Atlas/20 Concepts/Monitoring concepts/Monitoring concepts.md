# Monitoring concepts

How monitoring works and how to make alerts worth answering.

Part of [[Concepts]].

- [[WMI]]: Windows Management Instrumentation: how agentless tools query Windows performance and configuration.
- [[Monitoring thresholds and baselines]]: Set thresholds from what is normal for that system, not from defaults.
- [[Alert fatigue]]: When too many low-value alerts train people to ignore all alerts.
- [[Agent heartbeat]]: Agents check in on a schedule; a missed check-in raises an offline alert.
- [[Synthetic monitoring]]: Scripted checks that act like a user: load a page, log in, query an API.
- [[Monitoring vs observability]]: Monitoring tells you something is wrong; observability helps you find out why.
- [[Environmental monitoring]]: Temperature, humidity, water and power sensors in server rooms and racks.
- [[MTTA & MTTR]]: Mean time to acknowledge and mean time to resolve (or restore).
