# JumpCloud

> [!abstract] In plain words
> A cloud directory for companies with a mix of Windows, Mac and Linux.
>
> **What kind of tool is this?** Identity tools hold user accounts and decide who can sign in to what. When identity breaks, nobody can work.

**Made by:** [[JumpCloud]] · **Runs:** Cloud · **Category:** [[Identity & Access]]

Cloud directory for mixed Windows, macOS and Linux fleets: user management, SSO, MFA, device policies and RADIUS.
