# Azure OpenAI Service

> [!abstract] In plain words
> OpenAI's models (like GPT) hosted inside Azure, so companies can build AI apps with Azure security and data controls.
>
> **What kind of tool is this?** AI assistants answer questions, write drafts and summarize information from your work data. Admins control what data they can see.

**Made by:** [[Microsoft]] · **Category:** [[Cloud & SaaS]] › [[AI assistants]]

> [!info]+ Words on this page
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> *More in the [[Glossary]].*

## In more detail

OpenAI models deployed in an Azure subscription with private networking, Entra ID auth, content filtering and regional data handling.
