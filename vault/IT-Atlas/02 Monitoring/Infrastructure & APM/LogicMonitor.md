# LogicMonitor

> [!abstract] In plain words
> A cloud monitoring service: small 'collectors' at each site gather data and send it to the LogicMonitor portal.
>
> **What kind of tool is this?** These tools collect numbers (CPU, memory, response times) from servers, apps and cloud services and draw them as graphs, so you can spot trouble before users notice.

**Made by:** [[LogicMonitor]] · **Runs:** SaaS with on-site collectors · **Category:** [[Monitoring & Observability]] › [[Infrastructure & APM]]

> [!info]+ Words on this page
> **CPU**: The processor, the part of a computer that does the calculations.
> **SaaS**: Software as a service: apps you use online, such as Microsoft 365.
> **threshold**: The value that triggers an alert.
> *More in the [[Glossary]].*

## In more detail

SaaS infrastructure observability (LM Envision): collectors poll servers, network, storage and cloud using DataSources, with logs and AIOps on top.

## Main parts

- Collectors
- DataSources, EventSources and PropertySources
- Dashboards and alert rules
- LM Logs

## Alerts you'll see

- Collector down
- Threshold alerts
- No data
