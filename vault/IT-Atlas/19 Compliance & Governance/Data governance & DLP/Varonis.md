# Varonis

> [!abstract] In plain words
> Software that maps who can access which files and spots unusual access, such as ransomware or an insider copying data.
>
> **What kind of tool is this?** Data governance finds where sensitive data lives, labels it and stops it leaking (data loss prevention).

**Made by:** [[Varonis]] · **Category:** [[Compliance & Governance]] › [[Data governance & DLP]]

> [!info]+ Words on this page
> **DLP**: Data loss prevention: rules that detect and stop sensitive data leaving.
> **ransomware**: Malware that encrypts files and demands payment to unlock them.
> *More in the [[Glossary]].*

## In more detail

Data security platform: permissions analysis for file shares and Microsoft 365, data classification and behaviour-based alerts.
