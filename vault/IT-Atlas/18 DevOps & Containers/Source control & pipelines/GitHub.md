# GitHub

> [!abstract] In plain words
> The most popular place to store code and scripts in Git repositories, with pull requests for reviewing changes.
>
> **What kind of tool is this?** Source control keeps every version of code and scripts. CI/CD pipelines test and deploy changes automatically when someone pushes.

**Made by:** [[Microsoft]] · **Runs:** Cloud (github.com) or GitHub Enterprise Server · **Category:** [[DevOps & Containers]] › [[Source control & pipelines]]

> [!info]+ Words on this page
> **CI/CD**: Continuous integration and delivery: automatic testing and deployment of every change.
> **API**: A way for programs and scripts to talk to a service directly, without the web page.
> **pull request**: A request to review and merge changes from one branch into another.
> **pipeline**: A series of automated steps (test, build, deploy) that run on every change.
> **container**: A packaged app with everything it needs to run, sharing the host's operating system kernel.
> **branch**: A separate line of changes in Git, merged back into main after review.
> *More in the [[Glossary]].*

## In more detail

Hosted Git with pull requests, code review, issues, Actions (CI/CD), Packages and security scanning (Dependabot, secret scanning).

## Good to know

- Turn on branch protection for main: require pull requests and reviews before merging.
- Never commit passwords or API keys; secret scanning will flag them but they're already exposed.
