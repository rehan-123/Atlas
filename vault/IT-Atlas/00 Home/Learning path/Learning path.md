# Learning path

> [!tip] New to the NOC? Start here.
> Ten short weeks that take you from computer basics, through everyday help desk fixes, to running NOC alerts on your own. Each week has notes to read, hands-on practice and questions to check yourself. Tick the boxes as you go.

## How to study each note

1. Read the **In plain words** box first.
2. Skim the **Words on this page** box for any term you don't know.
3. Read the rest, then answer the **Check yourself** questions before revealing the answers.
4. Do the practice tasks on a real machine, in a lab or with a senior engineer watching.
5. Write what you learned in the note's **Field notes** section, in your own words.

## The weeks

| Week | You'll learn |
|---|---|
| [[Week 1 - Computer basics]] | Understand what's inside a computer, how files and accounts work, and how a PC reaches the internet. |
| [[Week 2 - Fixing everyday problems]] | Learn the help desk method and the ten problems you'll fix most often. |
| [[Week 3 - How networks work]] | Understand how two computers find and talk to each other. Everything else builds on this. |
| [[Week 4 - Windows and identity]] | Learn how logins work in a Windows domain and Microsoft 365, and where Windows records what happened. |
| [[Week 5 - Monitoring and the RMM]] | Learn how the NOC sees problems, and how to tell a real alert from noise. |
| [[Week 6 - Backup and recovery]] | Understand how backups work, why they fail, and how to prove they can be restored. |
| [[Week 7 - Security basics]] | Learn the security tools you'll see daily and what to do in the first minutes of an incident. |
| [[Week 8 - Network gear and remote access]] | Learn firewalls, switches, Wi-Fi and VPNs well enough to triage a site outage. |
| [[Week 9 - Servers, virtualization, storage and cloud]] | Understand where servers really run, and the hardware and cloud underneath them. |
| [[Week 10 - Running the NOC]] | Learn how incidents are prioritized, handed over and closed properly. |
