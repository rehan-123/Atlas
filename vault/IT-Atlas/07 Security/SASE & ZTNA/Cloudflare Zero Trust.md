# Cloudflare Zero Trust

> [!abstract] In plain words
> Cloudflare's service for secure access to company apps and filtered internet browsing.
>
> **What kind of tool is this?** These cloud services replace the old office VPN: users get to the apps they're allowed to use, from anywhere, with security checks on every connection.

**Made by:** [[Cloudflare]] · **Runs:** Cloud · **Category:** [[Security]] › [[SASE & ZTNA]]

> [!info]+ Words on this page
> **VPN**: An encrypted tunnel over the internet to a private network.
> **SASE**: Cloud-delivered network security that protects users wherever they are.
> **ZTNA**: Zero-trust network access: app-by-app access with checks on every connection, replacing a broad VPN.
> **DNS**: The service that turns names (like server01.contoso.local) into IP addresses.
> **tunnel**: An encrypted connection that carries traffic across another network.
> **port**: A numbered door on a device that a specific service listens on, for example 443 for HTTPS or 3389 for RDP.
> *More in the [[Glossary]].*

## In more detail

Cloudflare's SASE: Access (ZTNA), Gateway (DNS and web filtering), Tunnel (publish internal apps without opening inbound ports) and the WARP client.
