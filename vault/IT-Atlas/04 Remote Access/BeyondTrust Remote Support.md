# BeyondTrust Remote Support

> [!abstract] In plain words
> An enterprise remote support tool (formerly Bomgar) that records every session.
>
> **What kind of tool is this?** Remote access tools let you see and control someone's screen, or log in to a server, from wherever you are.

**Made by:** [[BeyondTrust]] · **Runs:** Appliance, cloud or self-hosted · **Category:** [[Remote Access]]

## In more detail

Enterprise remote support (formerly Bomgar) with session recording and granular access control.

## Good to know

- December 2024: attackers used a stolen API key for BeyondTrust's Remote Support SaaS to reach US Treasury workstations.
