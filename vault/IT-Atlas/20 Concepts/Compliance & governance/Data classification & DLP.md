# Data classification & DLP

> [!abstract] In one line
> Labelling data by sensitivity and using data loss prevention rules to stop it leaving the organization.

> [!tip] Think of it like
> Colour-coded folders in a law firm: red files never leave the building.

> [!info]+ Words on this page
> **DLP**: Data loss prevention: rules that detect and stop sensitive data leaving.
> *More in the [[Glossary]].*

## How it works

- Typical labels: Public, Internal, Confidential, Highly confidential.
- Labels can encrypt files and add markings; DLP policies detect patterns (card numbers, ID numbers) and block or warn.
- Start in audit mode to see what would be blocked before enforcing.
