# Compliance & governance

The security and privacy frameworks clients get audited against, in plain words.

Part of [[Concepts]].

- [[SOC 2]]: A US audit report showing a service company has working security controls, based on the AICPA Trust Services Criteria.
- [[ISO 27001]]: An international standard for running an information security management system (ISMS), certified by an external auditor.
- [[HIPAA]]: US law protecting health information; any IT provider handling patient data for a clinic must follow its Security Rule.
- [[PCI DSS]]: The card industry's security standard for anyone who stores, processes or transmits payment card data.
- [[NIST Cybersecurity Framework]]: A widely used US framework that organizes security into six functions: Govern, Identify, Protect, Detect, Respond and Recover.
- [[CIS Controls]]: A prioritized list of 18 security controls from the Center for Internet Security, grouped into Implementation Groups by maturity.
- [[Cyber Essentials]]: A UK government-backed certification covering five basic controls; often required for UK public-sector contracts.
- [[Essential Eight]]: Australia's eight priority mitigation strategies against cyber attacks, measured at maturity levels.
- [[GDPR and data privacy laws]]: Laws that control how personal data is collected and handled, such as the EU GDPR and India's Digital Personal Data Protection Act, 2023.
- [[Data classification & DLP]]: Labelling data by sensitivity and using data loss prevention rules to stop it leaving the organization.
