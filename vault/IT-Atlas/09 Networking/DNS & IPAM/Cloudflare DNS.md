# Cloudflare DNS

> [!abstract] In plain words
> Cloudflare's service for hosting a domain's DNS records, with built-in protection.
>
> **What kind of tool is this?** These tools manage domain names (DNS) and keep track of which IP addresses are in use.

**Made by:** [[Cloudflare]] · **Runs:** Cloud · **Category:** [[Networking]] › [[DNS & IPAM]]

> [!info]+ Words on this page
> **DNS**: The service that turns names (like server01.contoso.local) into IP addresses.
> **IP**: Internet Protocol address: a device's address on the network, like 192.168.1.20.
> *More in the [[Glossary]].*

## In more detail

Authoritative DNS hosting with proxying, DDoS protection and the 1.1.1.1 public resolver.
