# How a computer works

> [!abstract] In one line
> A computer has a brain (CPU), short-term memory (RAM) and long-term storage (disk).

> [!tip] Think of it like
> A kitchen: the CPU is the chef, RAM is the worktop, storage is the fridge and cupboards. A small worktop or a slow chef means meals take longer.

> [!info]+ Words on this page
> **CPU**: The processor, the part of a computer that does the calculations.
> **RAM**: Memory: the computer's short-term workspace for open apps. Cleared when you restart.
> **SSD**: Solid-state drive: fast storage with no moving parts. Much quicker than an old hard disk.
> **Task Manager**: Windows tool (Ctrl+Shift+Esc) that shows running apps and what's using CPU, memory and disk.
> *More in the [[Glossary]].*

## How it works

- **CPU** (processor): does the thinking. When it's at 100%, everything waits.
- **RAM** (memory): the desk space for what's open right now. Cleared when you restart.
- **Storage** (SSD or hard disk): the filing cabinet that keeps files when the power is off. SSDs are much faster than old spinning disks.
- **Operating system** (Windows, macOS): the manager that shares the CPU, RAM and storage between apps.
- Most "slow PC" problems come down to one of these being full or busy. Task Manager (Windows) or Activity Monitor (Mac) shows which.

## Check yourself

Answer in your head first, then click to reveal.

> [!question]- A user has 30 browser tabs open and the PC crawls. Which part is probably full?
> RAM (memory). Each tab uses memory; when RAM is full Windows starts using the much slower disk.

> [!question]- What's the difference between RAM and storage?
> RAM holds what's open right now and is cleared on restart. Storage keeps files when the power is off.
