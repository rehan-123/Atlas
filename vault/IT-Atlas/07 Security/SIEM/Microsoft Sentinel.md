# Microsoft Sentinel

> [!abstract] In plain words
> Microsoft's cloud SIEM: it collects security logs and raises incidents when something looks like an attack.
>
> **What kind of tool is this?** A SIEM collects security logs from everywhere and looks for patterns that mean an attack.

**Made by:** [[Microsoft]] · **Runs:** Azure · **Category:** [[Security]] › [[SIEM]]

> [!info]+ Words on this page
> **SIEM**: A system that collects security logs from everywhere and looks for attacks.
> **KQL**: Kusto Query Language, used to search logs in Sentinel, Defender and Azure Monitor.
> *More in the [[Glossary]].*

## In more detail

Cloud SIEM and SOAR on a Log Analytics workspace: data connectors, analytics rules written in KQL, incidents and Logic Apps playbooks. Increasingly run from the unified Defender portal.

## Main parts

- Log Analytics workspace
- Data connectors
- Analytics rules (KQL)
- Incidents
- Playbooks (Logic Apps)
- Workbooks
