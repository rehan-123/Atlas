# Passwords and password managers

> [!abstract] In one line
> Long unique passwords, stored in a password manager, plus MFA.

> [!tip] Think of it like
> A different key for every door, all on one secure keyring that only you can open.

> [!info]+ Words on this page
> **MFA**: Multi-factor authentication: password plus a second proof, such as a phone prompt.
> *More in the [[Glossary]].*

## How it works

- Length beats complexity: a long passphrase is stronger than a short complex word.
- Never reuse work passwords on other sites; breaches elsewhere get tried here.
- A password manager (Bitwarden, Keeper, 1Password) remembers them so you don't have to.
- IT will never ask for your password.

## Check yourself

Answer in your head first, then click to reveal.

> [!question]- Why is password reuse dangerous?
> When another site is breached, attackers try the same email and password on work accounts.
