# SOC 2

> [!abstract] In one line
> A US audit report showing a service company has working security controls, based on the AICPA Trust Services Criteria.

> [!tip] Think of it like
> A restaurant hygiene inspection: Type I checks the kitchen is set up right; Type II checks it stayed clean for months.

> [!info]+ Words on this page
> **MSP**: Managed service provider: a company that runs IT for other companies.
> **SOC**: Security operations center: the team that watches for and responds to attacks.
> **onboarding**: Setting up a new starter's accounts, access and devices.
> **offboarding**: Removing a leaver's access while keeping their data for the business.
> *More in the [[Glossary]].*

## How it works

- Criteria: Security (required), plus optionally Availability, Confidentiality, Processing Integrity and Privacy.
- **Type I** checks controls are designed properly at a point in time; **Type II** checks they actually worked over a period (often 6-12 months).
- MSPs often need SOC 2 because clients ask for it in security questionnaires.
- Evidence includes access reviews, change records, backup tests, onboarding/offboarding records and monitoring.
