# Synology Active Backup for Business

> [!abstract] In plain words
> Free backup software that runs on a Synology NAS and backs up PCs, servers, VMs and Microsoft 365.
>
> **What kind of tool is this?** Image backup copies a whole machine (operating system, apps and data) so it can be rebuilt exactly as it was.

**Made by:** [[Synology]] · **Runs:** Synology NAS · **Category:** [[Backup & DR]] › [[Image & server backup]]

> [!info]+ Words on this page
> **NAS**: Network-attached storage: a box full of disks that shares files over the network.
> **VM**: Virtual machine: a computer that runs as software on a physical server.
> **DR**: Disaster recovery: getting systems back after a major failure.

Free backup suite on Synology NAS for PCs, servers, VMware and Hyper-V, file servers, and Microsoft 365 or Google Workspace.
