# Git

> [!abstract] In plain words
> Keeps every version of your scripts, so you can see what changed and undo mistakes.
>
> **What kind of tool is this?** Scripting and automation tools let you do a task once in code and then repeat it on hundreds of machines.

**Runs:** CLI with GitHub, GitLab or Azure DevOps · **Category:** [[Automation & Scripting]]

> [!info]+ Words on this page
> **CLI**: Command-line interface: typing commands instead of clicking.
> *More in the [[Glossary]].*

## In more detail

Version control for scripts, configs and documentation. If a script runs in production, it belongs in Git.

## Handy commands

Words in CAPITALS are placeholders: replace them with your own values before running.

```
git status
git log --oneline -10
git diff
```
