# Operating system

> [!abstract] In one line
> The main software that runs the computer and lets apps use its hardware.

> [!tip] Think of it like
> The building manager: apps are tenants, and the manager decides who gets which room, power and keys.

> [!info]+ Words on this page
> **driver**: Small program that lets the operating system talk to a piece of hardware, like a printer or graphics card.
> **tenant**: One organization's own space in a cloud service such as Microsoft 365.
> *More in the [[Glossary]].*

## How it works

- Windows on most business PCs, macOS on Macs, iOS and Android on phones, Linux on many servers.
- It handles sign-in, files, networking, drivers, updates and security.
- Each version has an end-of-support date; after that it gets no security fixes.
