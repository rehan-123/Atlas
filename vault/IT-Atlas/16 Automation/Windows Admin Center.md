# Windows Admin Center

> [!abstract] In plain words
> Manages Windows servers from a web browser.
>
> **What kind of tool is this?** Scripting and automation tools let you do a task once in code and then repeat it on hundreds of machines.

**Made by:** [[Microsoft]] · **Runs:** Gateway installed on a server or PC · **Category:** [[Automation & Scripting]]

> [!info]+ Words on this page
> **browser**: The app you use to open websites: Edge, Chrome, Safari or Firefox.
> **cluster**: Several servers working together so one can take over if another fails.

## In more detail

Browser-based management for Windows Server, clusters, Hyper-V and Azure Local, from a gateway.
