# Cloud & DevOps concepts

How cloud services, containers, pipelines and infrastructure as code work.

Part of [[Concepts]].

- [[IaaS, PaaS and SaaS]]: Three ways to rent IT: rent the servers (IaaS), rent a platform to run your code (PaaS) or rent the finished app (SaaS).
- [[Containers vs virtual machines]]: A VM pretends to be a whole computer with its own OS; a container shares the host's OS and packs just the app.
- [[Source control & branching]]: Keeping every version of code and scripts in Git, and making changes on branches that are reviewed before merging.
- [[Continuous integration and delivery]]: Automatic steps that test and deploy every change: continuous integration (test it) and continuous delivery (ship it).
- [[Infrastructure as code]]: Describing servers, networks and settings in files, so they're built the same way every time by a tool.
- [[Secrets in scripts]]: Passwords and API keys must never be typed into scripts; scripts should fetch them from a vault at run time.
- [[Landing zones]]: A ready-made, secure starting layout for a cloud tenant: subscriptions, networks, identity and policies set up before workloads move in.
- [[Cloud cost management]]: Cloud bills grow quietly; tagging, right-sizing and shutting things down are how you control them.
- [[AI in IT operations]]: Using AI assistants to summarize tickets, write scripts and search knowledge, with a human checking the result.
